# SIH Pitch — 90 Seconds

### Hook
“Imagine knowing not only where a landslide is happening, but where the next failure is becoming more likely — and which road or settlement should be protected first.”

### Problem
NER has fragile terrain, intense rainfall and difficult connectivity. Existing information can be fragmented across weather, field teams, GIS and incident reports.

### Solution
LandslideGuard NER is an AI decision-intelligence platform that fuses environmental, terrain, historical and field evidence.

It gives every monitored zone:
- hazard probability
- confidence
- explanation
- exposed-asset score
- operational priority

### What makes it different
Our core innovation is **Hazard × Impact**, not just hazard.

Then we add a **Digital Twin** so officials can simulate rainfall and saturation scenarios.

Finally, the loop closes with **field reports + photographs + multilingual alerts**.

### Impact
The objective is not to replace experts. It is to create more decision time, better prioritization and faster verification.

### Roadmap
We start with a self-contained prototype, then integrate approved weather/sensor/satellite feeds, PostGIS, offline mobile collection and validated regional ML models.

### Closing
“LandslideGuard turns fragmented signals into one actionable picture — so NER can move from reacting to landslides to preparing for them.”
